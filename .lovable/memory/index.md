Design system constraints and project-wide rules.

## Tabs styling
- TabsList: no background (transparent, no bg-muted)
- TabsTrigger inactive: bg-background, border border-secondary, text-secondary-foreground
- TabsTrigger active: bg-primary, text-primary-foreground, border-primary, shadow-sm
- Custom inline tab buttons must follow the same pattern
- This applies globally — never use grey/muted for active or container

## Table headers
- Use bg-primary text-primary-foreground for table/list headers (not bg-muted)
- Calendar weekday headers: bg-primary text-primary-foreground

## Calendar grids
- Weekday headers use primary color, not muted grey
